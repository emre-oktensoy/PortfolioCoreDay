
PortfolioCore - Dinamik Kişisel Web Projesi

PortfolioCore, ASP.NET Core teknolojisiyle geliştirilmiş, kişisel deneyimleri ve yetkinlikleri profesyonel bir şekilde sergileyen yenilikçi bir web projesidir. 
Bu proje de kişisel kariyer bilgileri, teknik beceriler ve tamamlanan projeler etkileyici bir dijital platformda sunmak için tasarlanmıştır.  
Kullanıcı dostu arayüzü, responsive tasarımı ve modern görünümüyle PortfolioCore, ziyaretçilere akıcı bir deneyim sağlamak amaçlanmıştır. 
Kullanıcı paneli ile birlikte Admin paneli tasarlanıp geliştirilmiş ve içerikte dinamik bir kontrol sağlanması hedeflenmiştir.
ASP.NET Core 9.0, Entity Framework Core ile güçlendirilmiş veritabanı yönetimi, LINQ tabanlı veri işlemleri ve Bootstrap ile zenginleştirilmiş görsel tasarım, projenin teknik altyapısını oluşturmaktadır.

Kullanılan Teknolojiler:
ASP.NET Core 9.0,
Entity Framework Core,
HTML, CSS, Bootstrap 5,
Razor View ve ViewComponent,
JavaScript ve SweetAlert2,
SQL Server
